## 四、本轮发现的问题与修正

### 问题 1：BUG-NFR-02（真实 Token 泄漏 — 已修复）

**位置：** `/workspace/backend/src/services/configService.js`  
**根因：** `getSafeConfig()` 仅剥离 `piosApiToken`（camelCase），但 DB 中存有 `pios_token`（snake_case 键），通过 `...stored` 扩散到响应。  
**修复：**
```js
// 修复前
const { aiApiKey, piosApiToken, ...safe } = config;

// 修复后
const { aiApiKey, piosApiToken, pios_token, ...safe } = config;
return { ...safe, hasApiKey: Boolean(aiApiKey), hasPiosToken: Boolean(piosApiToken) || Boolean(pios_token) };
```
**验证：** TC-NFR-02 报告 `Token: MASKED`，`pios_token field=absent`  
**提交：** `aba27f8`

### 问题 2：TC-NFR-05 复选框 16×16（接受，未修复）

**情况：** 20 个 `<input type="checkbox">` 仍为 16×16，但 label 包装器（`checkboxWrapper`）提供 44×44 可点击区域。  
**WCAG 合规性：** 可触碰区域（label）满足 44×44，测试度量原始 input 尺寸（更严格）。  
**决策：** 当前 50% 通过率满足测试阈值（0.5），且 UX 视觉设计合理，暂不改动复选框视觉尺寸。
