## Bug Found & Fixed

### BUG-M1-001: DELETE 204 causes SyntaxError — task not removed from UI

**File:** `/workspace/frontend/src/services/api.js`  
**Severity:** High (P1) — core delete feature completely broken before fix  

**Root cause:** The shared `request()` helper called `res.json()` unconditionally on all responses. `DELETE /api/tasks/:id` returns HTTP 204 No Content with an empty body. Calling `.json()` on an empty body throws `SyntaxError: Unexpected end of JSON input`. The `catch` block in `TaskItem.handleDelete` caught this error and called `toast(e.message, 'error')`, but **`dispatch({ type: 'REMOVE_TASK', payload: task.id })` was never reached**. The task stayed in the React UI even though SQLite had successfully deleted it.

**Fix applied to `/workspace/frontend/src/services/api.js`:**
```js
// Before (line 8):
const data = await res.json()

// After:
const data = res.status === 204 ? null : await res.json()
```

**Verification:** TC-M1-003 (delete removes task from UI) and TC-M1-004 (delete does not affect other tasks) both PASS after the fix.
